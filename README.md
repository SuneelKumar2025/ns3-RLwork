ns3-gym
============
This Code environment provides you with the implementation of two important aspects
1. Wi-Fi MLO
2. Scheduling MLO using reinforcement learning

To run this setup, you need to follow two steps
1.  For NS-3 MLO download my custom module for MLO (preferably in NS.3.36 version) and replace the Wi-Fi folder with this https://github.com/Fundacio-i2CAT/ns3-WiFi-MLO)
2.  Install the gym environment and keep the whole gym environment provided above
